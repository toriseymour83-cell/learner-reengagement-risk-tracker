# Sample Data Plan

This project will use fictional sample data only.

No real learner names, personal details, attendance records or support notes should be used.

## Planned sample files

| File name | Purpose |
|---|---|
| learners_sample.csv | Basic learner profile information |
| attendance_sample.csv | Attendance and missed session information |
| engagement_sample.csv | Work submission and contact information |
| interventions_sample.csv | Support actions and follow-up notes |
| learner_risk_summary.csv | Final reporting-ready output |

## Sample learner groups

The fictional dataset will include learners from different provision contexts, such as:

- EOTAS
- alternative provision
- SEND support
- NEET re-engagement
- supported internship
- online tutoring

## Data privacy note

All data in this project is fictional and created for portfolio purposes.

The project is designed to demonstrate data structure, risk scoring logic and dashboard planning without exposing any real learner information.
